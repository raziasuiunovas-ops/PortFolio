# razziyu - Personal Portfolio

Личное портфолио Разии Суюновой - начинающей AI Web Developer из Бишкека.

## 🚀 Технологии

- **React 18** - UI библиотека
- **Vite** - Build tool
- **Framer Motion** - Анимации
- **React Icons** - Иконки
- **React Scroll** - Smooth navigation

## 🎨 Особенности

- ✨ Современный creative editorial дизайн
- 🎭 Плавные анимации и transitions
- 📱 Полностью адаптивный (mobile, tablet, desktop)
- 🎨 Бордовая + белая цветовая система
- 💫 Интерактивные hover эффекты
- ⚡ Быстрая загрузка
- 🌐 One-page layout с smooth scroll

## 📦 Установка

```bash
npm install
```

## 🏃 Запуск

```bash
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.

## 🏗️ Сборка

```bash
npm run build
```
